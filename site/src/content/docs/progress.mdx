## Par parcours

Un point par leçon : gris pour une leçon pas ouverte, bleu pour une leçon lue,
vert pour une leçon terminée, gris foncé pour une leçon passée. Les petits
carrés sont ses questions de contrôle : vert pour une question réussie, bleu
pour une question tentée, gris foncé pour une question passée.
